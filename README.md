We use various tools to solve problems we encounter in daily life and to carry out our tasks.

Especially for things we encounter every day or frequently, there are certain items we certainly carry with us constantly.

Such tools and belongings are called **EDC (Every Day Carry).**

While the EDC concept includes ordinary items carried daily such as phones, glasses, wallets, wristwatches, and keys, when used specifically as **EDC Tool**, it generally refers to tools designed to solve daily problems and combining many different tools into a single object. The best-known example of this type of tool is multi-tools known as Swiss Army Knives.

EDC Tools can come in various forms. It could be a multi-purpose knife, a multi-purpose pliers, or even a multi-purpose keychain.

Nowadays, there are even multi-purpose pens. However, these pens contain very few tools. In fact, the number of tools in currently available multi-purpose pens does not exceed 9. Moreover, these are manufactured industrially, and there are very few DIY solutions in this field.

However, not anymore.

As Islamic Source, we are happy to present you the **"Impossible Pen".**

There are exactly **18 functions** in this pen.

Our aim while designing this pen was to provide a solution to various daily problems and to gather as many tools as possible in a single pen of portable size. Moreover, while doing this, instead of using expensive equipment or industrial solutions, we used a little sweat, handcraft, and a simple 3D printer.

And along with the maturation process of the idea, we offer you this project, completed in more than 6 months, completely for free. Our only request is for you to pray for us.

If you wish, you can produce and use this pen for yourself, if you wish, you can produce it as a gift for others, and if you wish, you can produce and sell this pen to create your own halal livelihood.

Even if you have modeling knowledge, you can edit the model file in the free and open-source FreeCAD program and create your own designs.

Without further ado, let's examine what the Impossible Pen offers:

And many other tools necessary to overcome many daily problems.

And above all, in a stylish, practical, and original form that brings all these functions together into a single tool that you can carry easily and safely every day, anywhere, instantly accessible whenever you need, in dimensions almost identical to an ordinary wooden pencil.

And going a step beyond that, in a way that you can make all these yourself at home.

## Printing Recommendations

- The model is prepared for FDM printers and may not work as intended on SLA and similar printers.
- The model is prepared using PLA+ filament; make sure different filament materials are suitable for the model before using them.
- Position the main body of the pen vertically with the tip facing upwards.
- Print the pen with a brim so it adheres to the print bed.
- Position the cap vertically with the glass breaker facing upwards.
- Print the cap with a brim so it adheres to the print bed.
- Place the other part horizontally parallel to the bed.
- Lower the layer height in slicing settings or make it adaptive. Layer heights of 0.2mm and below are recommended. Layer height is especially important for the opener part.
- It is recommended to use a 0.4mm nozzle and a heated bed.
- Set the infill density to 70%.
- Print parts one by one.

## Additional Notes

- Print quality may vary depending on your 3D printer and filament.
- The model in the images was printed with an Ender 2 Pro using Sunlu PLA+ 2.0 filament through a 0.4mm nozzle.
- The tolerance margins of the model are prepared based on the outputs of the above filament and machine. You may need to change tolerance margins according to your own needs.
- Especially the opener part should be used slowly and carefully; if there is a problem with the print, this part may break first.
- The performance of the blade, magnets, and other various tools depends on the quality of the materials you use.
